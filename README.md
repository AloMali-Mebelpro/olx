# Объявления — доска объявлений (OLX-style)

Платформа для размещения объявлений о продаже товаров с рекламными местами:
баннер сверху, левый и правый сайдбар, реклама в ленте объявлений.

Стек: Next.js (App Router) + TypeScript + Tailwind CSS + Prisma + SQLite.

## Возможности

- Просмотр объявлений с фильтрацией по категориям и поиском
- Страница объявления
- Форма создания нового объявления
- Рекламные слоты: `BANNER_TOP`, `SIDEBAR_LEFT`, `SIDEBAR_RIGHT`, `IN_FEED`
- Панель управления рекламой (`/admin/ads`) — добавление, включение/выключение, удаление

## Запуск локально

```bash
npm install
cp .env.example .env
npm run db:push   # создаёт SQLite базу по схеме
npm run db:seed   # наполняет демо-данными (категории, объявления, реклама)
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Добавление рекламы

Перейдите на `/admin/ads`, заполните название, выберите позицию (баннер сверху /
левый сайдбар / правый сайдбар / в ленте), укажите URL изображения и ссылку
для перехода по клику.

## Структура

- `prisma/schema.prisma` — модели `Category`, `Listing`, `Ad`
- `src/app/api/*` — REST API (объявления, категории, реклама)
- `src/components/AdSlot.tsx` — рендер рекламного блока по позиции
- `src/app/layout.tsx` — общий каркас с баннером сверху
- `src/app/page.tsx` — главная страница с сайдбарами и лентой
